# Покерные карточки

Статическое PWA без бэкенда: просмотр, оглавление, тренировка и корзина для покерных карточек 390×844.

## Запуск на ПК

```
npx serve -l 3000 .
```

Откройте http://localhost:3000. Чтобы открыть приложение с телефона в той же сети, используйте адрес `http://<IP-компьютера>:3000`, который покажет `serve`.

## Возможности

- **Карточки.** На экране одна карточка, она масштабируется под ширину и высоту экрана. Листать можно свайпом, кнопками ‹ › или стрелками на клавиатуре; счётчик показывает «3 / 12».
- **Оглавление.** Номер, название и метка надёжности A/B/C. Фильтр по группам «Блефы ривера» и «Перефолды» действует и в просмотре, и в тренировке.
- **Тренировка.** Сначала видны только заголовок, «кто» и вводный текст. После «Показать ответ» появляются кнопки «Знал» и «Не знал». Карточки с «Не знал» в следующем круге идут первыми.
- **Корзина.** «Убрать» (с подтверждением), затем «Вернуть» или «Удалить навсегда». Кнопка «Скопировать список удалённых» копирует номера в буфер. Состояние хранится только в `localStorage`, файлы карточек не удаляются.
- **Офлайн.** Есть manifest, service worker, apple-touch-icon и режим standalone. Шрифты Inter и JetBrains Mono лежат локально в `fonts/`.

## Как добавить карточку

1. Положите `V5_13.dc.html` (номер берётся из имени файла) в папку `incoming/`.
2. Выполните `python build.py` (или `python build.py путь/к/папке`).
   Скрипт вырежет корневой `<div>` 390×844 и `<style>` в `cards/13.html`, а затем обновит `cards.json`.
   Группа определяется автоматически: «Блефы ривера», если в `<title>` есть слово «блеф», иначе «Перефолды». Её можно поправить вручную в `cards.json`.
3. Закоммитьте `cards/13.html` и `cards.json`. Если менялись `app.js`, `app.css` или `index.html`, увеличьте `VERSION` в `sw.js`.

npm run check        # скриншоты и отчёт в check/
